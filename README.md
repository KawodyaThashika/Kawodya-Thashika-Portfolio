# Kawodya Thashika — Portfolio

Personal portfolio website of Kawodya Thashika, a Software Technology undergraduate focused on full-stack development, enterprise systems and databases.

🔗 **Live site:** https://kawodyathashika.github.io/Kawodya-Thashika-Portfolio/

## Features
- Light / dark theme toggle with saved preference
- Animated hero particle swarm that morphs ring → helix → wave → vortex → galaxy
- Filterable project grid
- Fully responsive, accessibility-aware

## Tech Stack
HTML5 · CSS3 · Vanilla JavaScript · Bootstrap Icons · Google Fonts

## Run Locally
```bash
git clone https://github.com/KawodyaThashika/Kawodya-Thashika-Portfolio.git
cd Kawodya-Thashika-Portfolio
```
Open `index.html` in your browser — no build step needed.
